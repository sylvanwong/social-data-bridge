设计说明

首页 · 新增板块

  • 新增独立分组「博主与搜索」，置于「音视频」分组下方，与现有信息架构解耦，后续同类功能可继续归入
  • 卡片规格完全复用：24px 线性图标（stroke 1.6）+ 14px/500 文案 + #E5E6EB 描边 + 8px 圆角，hover 态沿用现有粉底红边规则
  • 「NEW」标记仅为设计稿标注，上线时可去掉
  • 图标语义：博主搜索 = 人像 + 放大镜；搜索联想 = 放大镜 + 星号（联想/发散）

博主搜索 · 设置页

  • 获取设置仅两项（平台 + 关键词），与「关键词搜索获取」的表单心智保持一致，关键词支持批量（换行/逗号分隔）
  • 输出字段对齐需求：用户ID、昵称、头像、粉丝数、主页链接、认证信息，另含「平台」便于多平台数据混表
  • 沿用字段勾选网格（2 列）+ 字段映射折叠条 + 执行方式 + 底部主按钮，与「作品详情获取」页结构一一对应

搜索联想 · 设置页

  • 关键词为单行输入框（区别于批量场景），输入后下拉面板实时展示联想词，命中字符标红
  • 建议类型用轻量标签呈现：普通词 / 关联词用中性灰底，热搜词用品牌红浅底，克制不抢焦点
  • 输出字段：联想词、建议类型、关键词、平台；其余交互（映射、执行方式、主按钮）与现有页面完全一致

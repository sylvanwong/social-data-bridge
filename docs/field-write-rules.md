# 字段类型与写入规则

适用于聚合插件及独立作者搜索、搜索推荐词、评论助手。工作流、字段捷径及其与侧栏配合的边界见下文。修改字段创建、校验、映射、值转换或恢复写入时，按本文审核。默认类型用于新建字段；兼容类型用于已有列，两者不能混为一谈。

## 类型约定

| 字段 | 新建默认类型 | 已有列兼容类型 |
| --- | --- | --- |
| 作品链接（含旧名“视频链接”） | 链接 | 链接、文本 |
| 作者／评论者主页链接 | 链接 | 链接、文本 |
| 点赞数、回复数等数字字段，含热榜排名、热度值 | 数字 | 数字、文本 |
| 平台、作者名称、评论者名称 | 文本 | 文本、单选 |
| 作品类型 | 文本 | 沿用各入口现有兼容规则，本次不扩大范围 |
| 作品标签 | 多选 | 多选、文本 |
| 热榜标签 | 文本 | 文本 |
| 日期、附件、ID 及其他字段 | 沿用原类型 | 沿用原规则 |

热榜标签表示热点分类，与作品话题不同，不能因为同名就改成相同类型。封面链接、下载链接、头像等字段本次保持原规则，不因值是 URL 就批量改型。

## 链接转附件下载

浏览器下载转换接口返回的附件 URL 时，仅对 `xhscdn.com` 及其真实子域名设置 `referrerPolicy: no-referrer`，避免站外 Referer 导致 CDN 返回 403。按实际返回地址判断，不按原始输入链接或域名子串匹配；转存地址及其他平台保持原请求行为，不向媒体域名发送 API Key。沿用原转换、文件名、大小限制及写入流程，不为此强制转存或再次调用转换接口；下载仍失败时保留 HTTP 原错并走现有行失败统计。

手动批量输入按链接逐条处理：转换／下载／创建单元格失败时记住序号、链接和原始原因并继续；API Key 失效则中断。每条 `addRecords` 请求失败都按写入结果待核对处理，不计作确定失败，不自动重试或继续追加。最终区分已确认成功、确定失败、待核对及未处理数量；正常停止与待核对同时出现时仍显示警告。普通失败和未处理链接在原提示区保留，浮层消失不清除；正常停止且没有失败时，同样保留未处理链接，文案为“请仅处理未处理链接”，不提不存在的失败项；保留原输入和已写结果，提示仅处理失败／未处理项，待核对项先检查目标表。完成后解锁控件，新任务开始清理旧提示；不新增持久化、续写状态或一键重试。

## 平台专属指标

作品详情的 `coin_count` 使用「投币数」，在点赞数后显示，默认不勾选，旁边以 12px 灰字注明「仅B站」；立即执行和定时编辑保持一致。列名仍为「投币数」，新建为数字，旧数字／文本列沿用兼容规则。字段保持可见可选，支持混合平台，不按单条链接切换或隐藏。保留用户字段选择，旧任务快照不自动增加新字段。

仅消费详情已有值：真实零写 0，缺失／不适用按现有空值规则写空，不改成 0；未选择不建列、不写入该字段。请求失败继续走现有失败与重试流程，不作为成功空值。新旧飞书服务、定时写入、作品详情字段捷径及工作流保持相同字段 key 与空值语义；不为作者列表或关键词搜索新增逐条详情请求。

## 创建、校验与写入

- 作者信息定时任务写回当前表时，先按任务载荷已确定的来源表 ID 保存完整映射，再提交任务；配置保存失败则保留草稿并阻止任务提交。编辑已有任务先按原来源表加载配置，配置就绪后才允许保存，避免空草稿覆盖云端映射。沿用现有按表保存队列及读取归属判断。 当前表定时弹窗复用现有映射编辑区，配置未就绪时锁定编辑；半填映射被拦截后，可直接在弹窗内补全或删除再保存。

- 字段映射可选；无映射时沿用同名列及缺列补列规则。添加的任一映射行未同时选择源字段和目标字段时，编辑时不显示逐行重复提示；点击立即执行或保存定时任务时统一提示需补全或删除未完成的映射，并阻止启动或保存；不得静默忽略后请求业务、创建任务或补默认列。保留草稿，补全或删除后允许同页继续。目标配置加载完成后再检查当前映射；已有任务恢复仍使用原任务快照。

- 新建表或元信息确认缺列时，使用默认类型创建字段；已有列保留原类型，不自动改型、删除重建或迁移数据。
- 映射归属目标表：切表加载该表配置；三个工具页的当前表模式随飞书切表更新字段和映射；源链接字段按新视图中唯一同名的文本／链接列匹配新 ID，无匹配时清空选择，同页重新选择后可继续。源字段首次初始化独立于云端映射配置加载；云配置迟到返回不得重新发起源字段读取、打断用户切表后的读取或重试。源字段读取失败在字段选择区保留原原因并复用加载入口同页重试；重试期间显示读取中并锁定执行，成功后收起、恢复原选择，再次失败更新本次原因。源字段读取同样核对请求归属，旧表／旧视图迟到、切换手动输入或卸载后不覆盖当前选择；回归使用不同表的不同源字段 ID，并核对实际读取和写入原行。输出配置加载期间锁定映射编辑及自动保存；执行和停止等待期间固定原任务配置，收尾后加载最新选择的表。手动指定的已有目标表不随飞书当前表变化。保存尚未返回时，切回优先使用该表最新待保存快照，读取期间保存先完成或失败时保留已捕获配置；存在比该快照更新的成功保存时，优先采用该结果，不让旧列表回退缓存。读取时捕获的那份保存自身成功，也应复用已确认配置，不因旧读取失败而清空映射或继续禁用控件；读取前已完成的历史保存不能掩盖新的读取错误。较早成功不能覆盖较新失败草稿，其他表保存成功不改变当前表的读取错误，不回存旧草稿。保存收尾只清理自身快照。提取视频文案、小红书下载、链接转附件及热榜的映射同样适用，复用按表待保存快照和原保存队列；不得只在成功响应后更新缓存。三个工具页保存当前表映射时，以当前字段列表已确认的目标表为归属，在首次 await 前固定表 ID 和映射并登记快照，不重新查询活动表后再确定归属；当前表字段未就绪时不自动保存。热榜在等待云配置／字段之前捕获待保存配置，保存收尾只清理自身，不因期间保存已结束而恢复旧缓存。新建任务不携带旧表映射；切回原已有表时重新加载该表映射和写入方式，即使保留的表 ID 未变化。加载完成前不能按临时空映射创建任务。恢复已有任务仍以任务快照为准，不用表格缓存配置覆盖原任务。
- 云端输出配置与字段元信息分别确认成功。提取视频文案、小红书下载和链接转附件同样须等云配置读取成功并应用当前目标表映射后，才解锁映射编辑和自动保存；字段先返回不能提前解锁。网络错误与业务错误均保留原原因并复用云配置 loader 同页重试，不当作成功空列表；合法成功空列表保留原默认配置行为。重试成功按当前目标表恢复映射，不在只读加载中自动回存；切表和卸载分别检查当前应用归属与组件生命周期。使用已有表或更新当前表时，配置读取成功并应用目标表映射后，才允许校验补列、自动保存配置或创建新任务；失败不能视为无配置，不发送空映射覆盖云端记录，保留原错误并复用原入口同页重读。合法成功空列表允许默认字段，新建表不依赖旧表配置。提取视频文案、小红书下载、链接转附件的已有表／当前表执行入口同样先复用云配置及字段 loader 确认就绪，再校验补列和发起业务请求；在原同步校验之后、原忙碌与进度阶段完成该准备。复用在途云读取，已就绪时保留用户草稿，不额外重读；准备期间停止或卸载后不得继续业务处理。已有任务／待写结果使用原快照恢复，不能因云端草稿配置失败而丢失进度或改用当前草稿。配置已成功时继续保留用户本次编辑；初始或旧请求迟到不得覆盖较新结果。
- 卸载保护覆盖配置准备后的执行链。提取视频文案、小红书下载、链接转附件在字段校验、新建表、请求返回、轮询间隔、附件下载及 SDK 单元格准备的异步返回后，复用原卸载标记检查归属，再进入下一步；限流排队的下载在取得名额后也须检查。卸载后的失败不得被当作普通行失败或附件失败继续循环、创建空单元格或显示旧提示。已发出的请求／写入可能已经生效，不承诺撤销；其结果返回后不得再启动下一次请求、补列、切表或写入。
- 字段读取失败应保留 SDK 原错误，不能当作缺列自动补列。聚合评论、提取视频文案、小红书下载和链接转附件在目标字段读取失败或尚未就绪时，映射编辑与自动保存共用就绪判断，不能因仍有表 ID 而保存临时空映射；保留原错误并复用字段加载入口同页重试。重试仅重读原目标字段，不从旧配置缓存覆盖本次草稿、不自动补存失败配置；重试期间切换新建或卸载后，旧请求继续按原加载归属失效。字段加载结束不代表配置就绪；失败后执行须复用原加载入口重读，成功恢复该目标表的映射及写入方式后再校验／创建任务，不能以临时空映射补默认列。再次失败显示本次原错误，不发业务请求、不写表；切换目标或新建时原失败状态失效，恢复旧任务和续写仍以原任务快照为准。显式映射、标准字段名和已有旧名沿用原匹配逻辑，不擅自改写映射草稿。已有目标表（含当前行更新）须按显式映射的目标 ID 校验和准备格式，已映射字段不再按原名补列；目标缺失或类型不兼容时先报错，不能回退同名列。格式设置只影响实际目标列，保留未选原名列的格式。校验和实际写入使用同一份执行映射快照。
- 校验接受的类型必须能实际写入。使用目标列的实际类型及其 SDK `createCell`，不要按配置默认类型选择写入方式。 写入准备时读取到的实际类型仍须复用现有兼容判断，不能只依赖任务开始前的校验；不兼容时在值转换和创建单元格前报错，不提交当前行／批次，不把类型错误当作可跳过字段。兼容类型之间的切换继续按实际列转换，同页修正后可重试；不增加锁或自动改列。
- SDK 字段对象的构造类型与 `getType()` 的当前类型不同是两个边界：当前类型用于兼容校验，创建单元格的对象也必须匹配该类型。四插件复用各包的 `resolveWritableField`；已核对 SDK 0.5.0、1.0.2 没有公开刷新接口，仅在类型变化时定向删除该 ID 的 `fieldCache` 项并重新读取，不清整个表缓存、不改列。缓存已刷新时复用新对象；刷新读取失败保留原错误，仍拿到旧类型时拒绝写入。此为已安装 SDK 的局部兼容处理，升级 SDK 时重新核对缓存行为。
- `createCell` 的输入不是 `setRecord`／`setRecords` 的原始单元格载荷。更新记录时统一使用 `await cell.getValue()` 的转换结果，串行和并行路径一致；不能只对附件取转换结果、对链接等字段继续传原字符串。
- 链接列、文本列均接收原链接字符串，保留查询参数；不得为统一类型而截断链接。数字写入文本列时转换成字符串，保留 `0`；数字列仍写数字，文本列不设置数字格式。格式准备同样复用字段刷新后的对象和实际类型，不能用缓存的 `field.type` 决定数字／日期格式；没有格式配置的字段不额外读取或设置格式。
- 在现有取值／归一化之后，目标数字／日期列的 `null`、`undefined`、空字符串必须转为 `null` 再交给 SDK；文本列继续写空字符串，不能误写成文字 `null`／`undefined`。有效数字及日期零值保留 `0`，不得用真假判断替代空值判断；指标取值中已有的缺失默认零语义继续保留，不因修正 SDK 载荷而改变业务含义。
- 单选、多选、日期和附件沿用已有转换，不把数字兼容或链接兼容扩大到其他字段类型。不支持的类型仍给出字段名和允许类型，普通类型错误允许同页修改后重试，不要求关闭插件。
- 视频文案、小红书下载及聚合／独立推荐词的输出字段勾选独立于云端映射初始化；复用勾选就绪状态，在读取完成前锁定勾选和新任务执行，读取失败沿用默认字段。云端映射迟到不能覆盖用户已编辑的勾选，页面卸载后的读取结果不再更新或保存。
- 新建、追加、更新和恢复写入遵守同一约定。恢复保留原任务、目标表、字段选择、映射与检查点；不因默认类型变化另建表或重复写入已完成批次。聚合评论在提交请求前复制输出字段选择，随原任务持久化，后续批次及恢复均使用这份快照；暂停后修改的勾选继续作为后续任务草稿，不改变旧任务写入字段。历史评论任务未保存字段选择时，无法还原原勾选，保持按当前选择写入的旧行为，不根据映射猜测字段或迁移进度。
- 历史检查点如果仍保存旧的数字／日期空字符串，不能直接替换为 `null` 后当作可自动续写：旧快照未必包含新比较规则下的所有历史空白行 ID。沿用现有不一致核对保护，保留原进度并停止后续写入，先人工核对；不伪造归属或强行迁移检查点。本轮自动恢复保证覆盖新格式检查点，旧空串检查点可能需要人工处理，重新进入本身不保证解除该保护。
- 复用各入口现有校验和转换函数，不新增字段框架。本次仅涉及前端，后端请求和响应契约保持不变。

## 工作流、字段捷径与侧栏配合

| 入口 | 链接结果及写入边界 |
| --- | --- |
| 侧栏 | 新建作品／主页链接列默认链接类型，已有文本列继续兼容；按实际列类型创建单元格，更新使用 SDK 转换后的值 |
| 工作流捷径 | 链接结果保持 `ActionResultType.String`，当前工作流 SDK 没有 `Url` 结果类型；列表入口保持字符串数组及现有解析步骤。由后续飞书新增／更新记录节点写入目标列 |
| 字段捷径复合字段 | 链接子属性保持 `FieldType.Text`；已核对的 CLI 不支持复合字段 `Url` 子属性，不能照搬侧栏默认类型。已发布的 key、类型与结构保持兼容 |
| 附件捷径 | 保持原附件输出契约，不混入普通链接列的转换规则 |

- 配合使用是共享表格记录，不共享任务 ID 或进度。工作流写入后，插件选择同一张已有表及同一组目标列；有字段名差异时使用现有显式映射，不另建同义列。
- 工作流应保留平台及稳定的作品／作者／评论 ID，ID 使用文本，避免精度丢失。按各入口实际匹配规则执行：关键词搜索和作者作品按作品 ID；聚合作者搜索按作者 ID 及现有备用标识逻辑；作者信息及独立作者搜索按平台和作者 ID；聚合评论按评论 ID；作品详情输出到已有目标表的更新按平台和作品 ID，表格来源的当前行更新使用原记录 ID。共用表存在跨平台 ID 冲突或重复标识时，不承诺会自动选中用户期望的行。
- 插件需要更新原记录时选择“更新或新增”或已有“更新当前行”路径，不能使用追加模式代替更新。独立评论助手当前只追加，不承诺更新已有评论；没有更新能力的入口仍保持原边界。
- 工作流再次运行时，后续写表节点也应更新同一条记录（原记录 ID 或确定的唯一匹配），不要无条件新增。工作流自身重试的写表去重由该节点负责，不能套用侧栏任务的恢复检查点保证。
- 更新只影响已配置的输出列，保留未选择的列和原列类型；同字段被两边先后成功写入时，以后一次写入值为准。本次不增加跨入口锁、自动同步或共享任务机制。
- 工作流 `Timestamp` 返回毫秒；兼容已有秒／毫秒数字及数字字符串，保留零，空值和无效日期返回 `null`。带时间／时区的 ISO 先解析原文，失败后才沿用旧格式回退，不能预先替换其中的连字符。纯日期 `YYYY-MM-DD` 保留各入口原语义：关键词、作者作品、作者信息、评论沿用斜杠格式的运行时本地零点；详情在数值识别后先保留原始日期字符串的有效解析结果（标准纯日期为 UTC 零点，带首／尾空白的旧纯日期为本地零点），失败再尝试去空白及旧格式回退，不为统一写法改变旧值。字段提供备用时间时沿用原有取值顺序。
- 关键词和作者作品的标签数组复用同一处理约定：仅保留非空字符串、去除两端空白、按已有方式连接为文本；保留标签内部空格，原字符串保持原内容；无可用值时沿用备用 `caption`。输出仍为 `String`，不直接改成 `StringArray`。
- 标签文本与多选数组不能视为等价。真实 SDK 中，`['猫咪', '标签 二']` 写入两个选项，而 `'猫咪 标签 二'` 是一个选项；本地 SDK 验证不证明工作流宿主会自动转换。当前工作流标签仅保证文本目标列配合，多选目标列需先验收写表节点的输入及转换，不能按空格拆分后宣称兼容，也不自动迁移旧列。[飞书官方工作流说明](https://www.feishu.cn/hc/zh-CN/articles/170735237222-%E4%BD%BF%E7%94%A8%E5%A4%9A%E7%BB%B4%E8%A1%A8%E6%A0%BC%E5%B7%A5%E4%BD%9C%E6%B5%81)也要求同步字段使用相同或兼容类型。

## 审核与回归

1. 列出能力的聚合入口、独立入口、共用 owner，核对默认类型、兼容范围、实际值转换和 SDK 写入，不能只比较字段配置。
2. 检查标准字段名、已支持的旧名和显式映射；新建列符合默认类型，已有列元信息不变，缺列和读取失败边界不变。
3. 回归覆盖文本／链接列的链接写入，数字／文本列的数字写入（含 `0`）、追加、更新、恢复；验证返回数量和实际目标字段值，而非仅断言配置或源码字符串。
4. 保留不支持类型的失败用例，确认无误写、无改列；同页修正后可重试。已有日期、附件、单选、多选和 ID 的相关回归继续通过。
5. 区分源码核对、自动化测试和真实飞书验证；SDK 宿主替身不能证明真实飞书界面已经验收。构建和发布仍需用户明确授权。
6. 验证“工作流写入 → 插件更新原行 → 工作流再次更新”：覆盖链接／文本旧列、显式映射、数字零值、串行／并行和恢复更新；检查原记录 ID、数量、表、列类型及未选字段不变。至少一组回归使用真实 SDK `createCell/getValue` 转换，宿主替身应拒绝不符合列类型的更新载荷，不能用原样返回字符串的单元格替身证明链接更新可用。
7. 日期同时覆盖带时区 ISO、秒／毫秒及数字字符串、零、空白／无效值和备用字段；纯日期及无时区日期时间在 UTC、Asia/Shanghai 的独立进程中验证旧语义，不以带显式时区的日期代替。数字列验证真实数字零值，标签验证空数组、非字符串项、备用值、内部空格及字符串输出类型。多选 SDK 契约与真实飞书工作流写表节点的转换验收分别记录。
8. 空值联动必须覆盖 `null`、缺失、空字符串与有效零：工作流写入后插件更新／恢复，再由工作流更新原行；真实 SDK 转换后数字／日期载荷仅为数字或 `null`，文本列空值仍为空文本，原表、原列类型、原记录及未选字段保留。同类实际写入入口一起核查，不只修共用函数。
9. 空值追加写入生效后响应超时，恢复只能抵扣本失败批次确认落表的行，保留历史同内容行；旧空串检查点与新空值表示不一致时，验证仍保留核对保护、不继续写、不新增或覆盖历史行。

10. 校验通过后，在接口／字段读取等待期间将目标列改为不兼容类型，更新、追加和恢复写入均须拒绝当前行／批次，保留原值及列类型；同页改回兼容类型后可重试。覆盖普通文本误变日期导致空值清空、数字误变日期及实际 SDK 转换，不能仅断言首次校验失败。
11. 首次校验必须先用真实 SDK 缓存字段对象，再改变列类型：覆盖数字／文本双向转换、改成不兼容类型被拦截后同页改回兼容类型、当前行更新／追加／恢复、串行／并行，以及刷新失败和多行复用新对象。只替换 `getType()`，或首次创建 SDK 对象在改型之后，均不足以证明该边界。

12. 评论任务覆盖“暂停 → 修改输出字段 → 恢复原任务”：核对更新／追加、新建表初始化失败、映射目标、实际字段值与记录数，不因当前草稿变化漏写原字段或新增其他列。提交响应延迟时保存请求发出前的字段副本；空字段快照仍包含必填 ID，缺少快照的历史任务保持兼容行为。

13. 目标表异步配置读取须校验归属：A 表读取延迟时切到 B 表，旧成功／失败不得覆盖 B 的字段、映射或写入方式，不得解除 B 的加载状态或自动保存为 B 的配置；切换新建及卸载后也不继续旧读取。该约束也适用于评论、提取视频文案、小红书下载和链接转附件的目标字段选项；首次获取表句柄后及读取字段后均检查归属，“当前表”与“已有表”共用当前加载归属。旧请求不能清空新表选项或提前结束新表加载；没有云端配置的目标表也须正常结束自身加载，不误存空映射。独立作者在首次异步校验前复制输出配置，校验和创建任务保存同一份目标表、字段、模式及映射；不能在创建响应返回后重读当前草稿。回归使用真实 Vue watcher／生命周期，检查保存载荷和实际落表结果。目标配置未就绪、加载或读取失败时，写入方式和映射选择、添加／删除一起锁定；成功应用当前表配置后再允许编辑，不能在执行前重读时丢弃用户刚选的模式或目标列；选择“始终新增”必须实际追加并保留原行，配置就绪不能解除原任务的忙碌锁定。

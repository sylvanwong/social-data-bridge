# 聚合插件提示文案与样式最终稿

适用范围：聚合插件 `social-data-bridge`，以及独立作者搜索、搜索推荐词、评论助手。文案、样式及反馈时机已落实到代码；独立插件的本页续写、密钥锁定和连接提示保留各自已有功能。

## 样式与显示规则

- 主执行按钮沿用红底白字，悬停、键盘聚焦和按下时也保持可读；停止按钮沿用浅底红字，禁用态统一灰底灰字。Element Plus 的交互文字色和背景色需一起核对，不能只覆盖背景色。
- 任务按钮的键盘聚焦统一使用单框：仅将原边框加粗为 2px 并加深为同色系红色，不叠加外圈 `outline` 或焦点阴影。聚焦保持原有底色与文字色，不做反色；边框变化不得改变按钮外部尺寸或引起布局跳动。执行、停止、恢复及继续写入按钮采用同一规则。该规则已落实到四插件代码。
- “停止按钮聚焦”仅表示键盘 Tab 选中了“停止任务”按钮，尚未触发停止，任务仍在执行；只有点击或按 Enter、空格激活后，才进入“正在停止…”的加载、禁用状态。悬停和聚焦不改变任务状态，禁用按钮不响应激活，也不显示焦点框。
- 输入提示使用对应字段的名称：作者主页链接、作品链接。API Key 保持统一大小写，中文使用“密钥”；独立评论的密钥入口与其余插件统一为“点击获取API密钥”。旧表字段别名和接口参数不随界面文案调整。
- 任务提示直接复用 `CommentFetch.vue` 原模板及 CSS：居中、白底、8px 圆角、10px 18px 内边距、18px 图标、8px 图文间距、14px/500 文字、22px 行高和原阴影。提示框距插件两侧各至少 24px，长文本及连续链接自然换行；顶部 Message 同样使用 22px 行高及两侧留白。仍是图标加一段文字，不加标题、遮罩或关闭按钮。
- 加载及成功保留原 SVG；警告、错误、中性状态使用同风格的实心圆形 SVG 图标，分别为橙色、红色、灰色。失败和停止不显示绿色成功勾。
- 非停止的最终结果中，有成功且有逐条失败用警告，逐条处理全部失败用错误，全部请求成功但结果为空用中性图标。推荐词有失败关键词摘要时用警告，全部关键词获取失败用错误。服务端失败终态及实际执行异常保留错误语义。
- 最终已停止且失败数大于 0，统一用警告、5 秒，保留成功/失败统计；即使尚无成功记录，也不把用户停止误标成整批执行失败。没有失败的最终停止用中性、3 秒。该停止规则优先于一般逐条结果分类。
- 执行中持续显示，全部成功 3 秒消失，部分成功、无结果、普通失败 5 秒消失；字段类型不匹配错误的浮动提示为 8 秒，顶部同类字段错误同样为 8 秒；其他顶部提交校验 3 秒，主动保存失败 5 秒。需人工核对或重新打开的异常，浮层可在 5 秒后消失，但操作要求留在任务操作区；局部配置加载或错误在原区域保留到处理完成。
- 提示自动消失不改变任务状态；更新提示、新任务和卸载时清理旧计时器。同一错误只弹一次浮动提示；必须保留的操作区说明不是另一次弹窗。具体错误优先采用原接口或异常信息，不推测权限、密钥或超时原因。
- 普通输出字段类型不匹配属于可修正的校验错误，不标记必须重开，也不要求关闭插件。提示明确输出字段名称、支持类型及“请修正目标字段类型后重试”，释放本次执行忙碌状态，允许同页再次校验。独立推荐词已有本页待写结果时保留结果和原输出配置，显示“继续写入”，修正目标表字段后续写，不重复搜索。写入结果或任务状态无法确认的重开保护仍按原结构化标记执行，不因本规则解除。
- 同页重新校验字段时读取当前类型：聚合逐条处理页复用字段的 `getType()`，不使用SDK字段对象缓存的 `.type` 进行类型判断；同名字段和显式映射采用相同规则。
- 获取、写入、停止获取、停止后写入和最终停止分别表达。计数单位和动态内容保留原实现，不把搜索页、主页、关键词和结果记录混为一谈。

## 任务按钮样式、文案与动画

四插件各自的 `src/assets/main.css` 统一管理 `.el-button.commit-btn` 外观，页面保留原有布局及任务状态，不新增状态机。

- 尺寸：36px 高、6px 圆角、14px 字号、500 字重；`border-box` 保持聚焦前后的外部尺寸。
- 执行：默认 `#a8071a`、悬停 `#c11126`、按下 `#8a0515`，文字始终为白色；聚焦只将原边框强化为 2px 的 `#860515`。
- 停止：默认白底、悬停 `#fff1f2`、按下 `#ffe4e6`，文字始终为 `#a8071a`，默认边框 `#d5495c`；聚焦只将原边框强化为 2px 的 `#a8071a`。
- 禁用及加载：底色 `#fafafa`、文字 `#86909c`、1px 边框 `#e5e6eb`，不响应交互变色或显示焦点框；保留 Element Plus 加载交互保护，移除其白色蒙层底色，避免二次淡化。
- 颜色过渡 100ms，不添加缩放或闪烁；按钮加载图标沿用 Element Plus 的 2s 匀速旋转，居中任务提示沿用 0.8s 匀速旋转。减少动态效果时取消旋转和过渡。

| 已有状态 | 按钮文案 | 加载与可用性 |
| --- | --- | --- |
| 待执行 | `立即执行` | 可点击，无转圈 |

| 聚合增量任务已排空结果、正在清理恢复进度 | `执行中…` | 禁用并持续转圈；居中显示“正在清理任务进度…”，仍保持忙碌，不提供停止或新建 |

| 独立推荐词本页续写 | `继续写入` | 待续写时显示次要操作 `结束本次写入`；准备及写入期间隐藏，失败后恢复，全部完成后收起 |
| 可持久化恢复的任务必须重新进入（如身份或写入检查点保存无法确认） | `请重新进入插件恢复` | 复用现有重开标志禁用；原始原因及操作说明保留，同页换密钥不能绕过保护 |
| 没有原任务恢复能力的入口必须重新进入 | `请重新进入插件` | 禁用；只要求重开，不承诺恢复原任务。适用于逐条处理、热榜、推荐词及独立评论 |
| 保存 API Key | `立即执行` | 复用现有互斥禁用，不显示任务加载动画 |
| 成功、失败或最终停止，且没有遗留恢复保护 | `立即执行` | 任务结束后恢复可点击 |

独立作者只有在任务对象准备好、身份保存完成后才显示可点击的“停止任务”。恢复已有任务时，对象已就绪即允许停止，不因首轮轮询仍在等待而禁用；即使等待期间已经渲染按钮、恢复前后taskId相同，也必须刷新为对应的可停止或正在停止状态；配置和密钥仍保持忙碌锁定。任务对象已释放、恢复记录仍在清理时，显示禁用并转圈的“执行中…”，清理完成前不允许新建。SDK读取和身份保存等待期间离开实例，晚返回不能重建归属或触发就绪回调。

重开保护直到离开当前组件实例才解除，同页换密钥不绕过保护；普通鉴权暂停仍允许换密钥恢复原任务。新建任务身份或首轮进度保存失败时也保留保护，不允许再次创建覆盖已有任务；无法确认身份已保存时，按钮仅显示“请重新进入插件”，保留“任务已创建，但恢复进度未能确认保存，请先核对结果再重新进入插件，勿重复启动”的说明，不承诺重开可恢复。

独立推荐词的未写结果只保留在本页内存。需要重开时保留“关闭或刷新插件页面会清除本次未写入的结果，重新进入后需重新执行”，不新增持久化，也不将本页“继续写入”描述成重开可恢复。

独立推荐词的密钥锁定说明复用现有获取/写入、本页待写和重开保护状态：准备、获取、停止等待及实际写入期间显示“任务处理中，任务结束后可修改 API Key。”；存在未写结果且当前未执行、允许同页续写时，显示“本次写入尚未完成，完成写入或结束本次写入后可修改 API Key。”。已有重开保护时优先显示“请先按下方提示核对结果，结束本次写入后可修改 API Key。”，原始原因、重开说明和禁用主按钮仍保留，不承诺同页完成写入。继续写入期间恢复执行中说明，全部写完或明确结束本次写入后移除说明；密钥锁定条件保持不变。结束本次写入时复用反馈的hide清除旧浮层及其计时器，再清理原任务区说明，不新增结束弹窗。

### 停止能力与边界

| 入口 | 可停止阶段 | 停止后的处理 |
| --- | --- | --- |
| 聚合、独立推荐词 | 正在逐个获取关键词 | 等当前请求结束，不再获取后续关键词；已获取结果按原逻辑写完 |
| 独立评论助手 | 创建已返回taskId、后台仍在获取评论 | 使用与聚合评论相同的停止接口，继续轮询；确认终态后分页写完已保存评论 |
| 聚合五个增量入口及独立作者搜索 | 原后台任务获取阶段 | 沿用原停止请求及结果交付逻辑 |
| 聚合逐条处理入口 | 原逐条执行阶段 | 等当前记录处理完成，不再处理后续记录 |
| 热榜 | 单次获取 | 保持不可停止的“执行中…” |

- 推荐词获取中显示可点击的“停止任务”；点击后显示禁用、加载的“正在停止…”，进度为“正在停止获取推荐词，等待当前请求完成…”。进入写入后不提供新的停止操作；正常写入显示“执行中…”，已请求停止的写入保持“正在停止…”，写入进度与勿关闭提醒持续显示。
- 推荐词最终停止显示“任务已停止，已写入 {count} 条推荐词”，失败关键词数仍按实际摘要附加；有失败用警告、5秒，无失败用中性、3秒，包含0条结果。独立推荐词在停止后写入失败，仍保留本页结果及停止状态，“继续写入”不重复搜索，写完后保持实际停止结果。
- 独立评论在任务身份未就绪及普通终态写入期间，使用禁用加载的“执行中…”；后台任务就绪时显示“停止任务”，请求或确认停止后的等待及写入使用“正在停止…”。停止请求未返回仍继续轮询和交付结果，不因停止请求本身提前结束任务。
- 独立评论停止失败且尚未确认停止时，保留当前任务及加载提示，允许再次停止，另用顶部Message显示原始原因；轮询已确认停止、正在写入、任务已结束或旧任务迟到的停止失败，不得撤销当前停止状态或覆盖新任务提示。卸载后不得重新弹出旧停止错误。
- 聚合推荐词追加写入复用每批最多200条的分批逻辑，全部写入返回后才显示最终停止；写入失败保留原始原因并提示核对表格，不显示本入口没有提供的“恢复任务”。
- 三个入口卸载后，迟到的校验、获取、任务创建、结果列表及写入响应不再启动后续请求、轮询、字段设置或写入批次，也不切表或重新显示旧提示。已经发出的写入允许结束；这不等于跨页恢复，未写入结果仍服从原入口的进度保留范围。
- 三个入口复用既有按钮配色、聚焦与加载动画。没有新增后台任务接口、跨页续写或持久化恢复能力；准备、获取、停止等待及写入继续沿用忙碌和API Key互斥，不能重复提交或在写入未结束时放开新任务。

## 点击执行与勿关闭提醒（统一要求）

1. 点击“立即执行”后，先完成密钥、关键词、必填项等同步校验；校验失败直接显示具体错误，不闪现启动进度。已有任务正在执行或正在提交时继续沿用现有防重入逻辑。
2. 同步校验通过，立即进入现有忙碌状态并显示居中加载提示。必须放在首次异步操作之前，包括读取配置或表格、异步字段校验、创建或提交任务；不能等接口返回、取得任务 ID 或读完记录才显示。按钮加载与居中提示同时生效，按钮加载不能代替进度提示。
3. Vue 更新应能在后续工作前渲染，必要时沿用 `await nextTick()`；不人为增加等待时间。后续按读取、提交、获取、写入等真实阶段更新同一条提示；已有明确的首阶段文案时直接使用，不增加一闪而过的重复启动提示。
4. 启动、任务准备、读取任务数据、获取、核对、写入、恢复中，统一保留一次“请勿关闭插件，关闭将中断任务”。保留原有业务对象和阶段，只补齐缺失的提醒，不重复拼接。
5. 正在停止且仍有请求、处理或写入待完成时，显示“请勿关闭插件，关闭会中断数据写入”；共享停止函数原文保留。只有写入和停止收尾都完成，才显示不带该提醒的最终停止结果。
6. 成功、纯空结果、已结束的部分失败和整体失败、最终停止，以及普通配置加载、保存设置、参数校验，不加执行中勿关闭提醒。单条失败但整批继续不属于终态，仍保留执行进度和提醒。作为执行前置步骤的异步字段校验属于任务准备，需要提醒；设置页独立加载配置不属于任务准备。
7. 准备过程中失败或提前退出，必须用实际错误、空结果或未开始状态替换加载提示，并释放现有忙碌状态，不留下永久转圈。恢复、继续操作也适用首次异步前反馈规则。
8. 独立推荐词等待本页继续写入时，沿用明确的“关闭或刷新插件页面会清除未完成进度”说明；该状态不套用本节聚合任务的执行中文案。

## 审阅补齐：暂停、停止伴随失败、单条失败继续

停止请求失败但任务仍在获取或写入时，顶部 Message 只报告一次原错误。轮询尚未确认停止时，居中提示改为“任务继续执行，已写入 {writtenCount} 条{业务对象}”，持续保留加载和勿关闭提醒。若 `task.latestStatus` 已包含 `status=3`、`cancel_requested` 或 `status_text=cancel_requested`，保留原停止阶段文案、写入专用提醒和操作锁定，直到写入及真实终态收尾完成。停止操作失败不等于任务失败，不释放任务忙碌状态、不隐藏进度，也不重发在途写入。旧执行的响应继续服从已有任务对象归属判断。

聚合作者、关键词、主页、评论、短剧五个入口及独立作者搜索均保留轮询已确认的停止状态；恢复缓存中带有上述任一停止标记的任务时，首轮状态请求返回前即显示“正在停止…”、停止阶段提示及写入专用提醒，禁止重复发送停止请求。搜索接口的 `processed/total` 表示已获取的搜索页数，不代表待写入的作者数量；无法确认待写入数量时，沿用“正在停止任务，等待剩余作者写入完成后停止，避免已获取数据丢失”，不显示“剩余 N 页作者未写入”。

### 需要人工核对或重新打开的暂停状态

- 这类状态不是普通失败终态，不适用“5 秒后只剩恢复按钮”。保留原始错误和“先核对表格结果”“重新打开”“勿重复启动”等必要操作要求，直到本次任务恢复、结束或离开当前任务处理。浮层仍按 5 秒隐藏，任务操作区的普通说明继续显示。
- 直接复用原操作区及 `.sub-hint` 文字样式，靠近现有按钮显示可换行的说明。不新增卡片、弹窗、关闭/复制按钮、消息历史、核对勾选或二次确认。
- 普通可恢复异常保留“恢复任务”按钮，提示用户先核对再恢复；不自动重新提交。`requiresReopen` 等已有状态要求重开时，本页入口应禁用：有持久化恢复能力时显示“请重新进入插件恢复”，其余显示“请重新进入插件”；不能只给一个仍可执行的恢复按钮。沿用现有互斥和恢复逻辑，不引入新的重试或任务状态机。
- 聚合五个增量任务入口的任务状态、获取结果、恢复记录及当前表格读取超时，统一暂停并提示“{读取对象}超时，请稍后恢复任务”，保留原任务和进度，允许同页显式恢复；迟到的只读响应不得推进游标或启动写入。写入表格、保存进度、清理进度等操作仍沿用原重开及在途操作保护。
- 聚合五个入口未读取到当前表格的恢复进度时，提示“未读取到当前表格的恢复进度，请核对当前多维表格和已写入结果后重试恢复”，不承诺重开可以找回缺失记录，也不放开为新建任务。作品详情、作者信息、作者作品的输出配置未加载成功时，提示“输出表配置尚未成功读取，请重试加载后再保存”，继续使用现有重试加载入口。
- 独立作者读取恢复记录或当前多维表格失败，保留具体错误及“恢复任务”，允许同页显式重试读取，不要求关闭插件；尚未确认是否有原任务时，不可直接提交新任务。任务身份、批次检查点及进度保存失败继续保留原重开保护。
- 独立作者终态清理失败，不显示“处理完成”或开放新建任务；提示“清理任务进度失败，请重试恢复以完成清理：{原因}”，保留“恢复任务”。重试只恢复原任务并确认清理；若上次清理已生效，确认恢复记录为空即可回到“立即执行”。卸载后迟到的清理失败不得改写旧页面反馈。
- 聚合五个增量入口读取状态或结果遇到密钥失效（INVALID_API_KEY、HTTP 401/403），立即停止本地轮询，显示具体错误及“恢复任务”；更新密钥后沿用原任务和游标恢复，不继续无效轮询，也不要求重开插件。
- 聚合五个入口已确认终态并排空结果、仅剩清理进度时，保留当前任务对象及已确认的终态。同页恢复只重试清理，不重新获取或写入；即使上次清理已生效但响应报错、恢复记录为空，也能完成收尾。仅适用于本页已知的待清理任务，不将其他缺失恢复记录视为完成；当前多维表格不匹配时不得清理，存储已被其他任务替换时不得清除新任务。清理超时或尚未结束的在途保护继续有效。
- 聚合五个入口清理进度期间，主按钮使用禁用加载的“执行中…”，不再发送停止请求；旧停止请求在此期间失败时，不覆盖清理提示、不显示“任务继续执行”。清理成功后按原成功、失败或停止状态收尾；清理失败则退出忙碌并按原规则保留恢复或重开保护。
- 聚合业务请求层将HTTP 401/403统一识别为已有的INVALID_API_KEY，保留后端msg、原HTTP状态及响应信息，五个逐条处理入口沿用原致命错误退出逻辑，不再继续后续记录；普通网络、HTTP 500、附件资源下载失败仍按各自原逻辑处理。
- 独立评论轮询收到业务错误4001或HTTP 401/403时，复用停止轮询及失败收尾，立即显示接口原因并释放忙碌及密钥编辑限制，不等待10分钟超时，不要求重开。已退出轮询或旧任务迟到的鉴权失败不得影响新任务；不新增独立评论的持久化恢复能力。
- 两个推荐词入口收到业务错误4001或HTTP 401/403时，停止后续关键词获取，不显示“整批任务继续执行”。没有结果时显示具体错误；已有结果仍沿用原写入逻辑，收尾使用警告及“已写入 {count} 条（{原统计}，获取已中止：{原因}）”，不显示整批“处理完成”。独立推荐词写入失败继续保留本页结果及中止原因，“继续写入”不重复搜索；普通关键词错误仍按原规则继续后续关键词。
- 只有已确认仍在获取、写入或恢复时才显示执行中勿关闭提醒。上述暂停说明不得拼接“请勿关闭”，避免与“请关闭当前插件后重新打开”的实际要求冲突。

### 已停止且已有失败

保留“任务已停止：成功 {successCount} 条，失败 {failCount} 条”。`failCount > 0` 时警告图标、5 秒；没有失败时中性图标、3 秒。尚有结果在写入时仍是加载和停止收尾提醒，不能提前套用本终态规则。

### 单条失败但整批仍继续

- 只适用于原逻辑允许继续的记录级错误；`INVALID_API_KEY` 等原本终止整批的错误继续走整体异常处理，不得吞掉。
- 单条失败不隐藏居中加载、不释放忙碌状态、不移除勿关闭提醒。按真实下一阶段更新同一条进度；不逐条弹整批完成或失败提示。
- 最近一条的原错误可复用操作区普通说明展示，并补明“整批任务继续执行”，后续同类说明原位更新，不堆叠多个浮动错误。具体原因按实际异常填入，“请求失败”仅为原有兜底。
- 结束时复用已有成功/失败计数汇总，部分失败用警告，确属整批全部失败用错误；若用户停止，优先适用上面的停止统计规则。不新增失败日志面板、重试队列或单条重跑能力。

## 后续实现验收

### 审核范围与证据

- 独立评论初始化复用现有就绪标记，字段勾选、API Key 和作品链接全部读回后才允许编辑、保存密钥和执行。等待时任务按钮显示禁用加载的“准备中…”，不把尚未读回误报为缺少密钥；读取失败保留原原因并提供同页“重试”，重试复用同一加载入口，失败前不解锁。有效空值及清除标记沿用原规则，就绪后缺少密钥才提示配置。卸载后的返回不更新旧实例，也不继续读取下一项配置。

- 卸载回归须覆盖配置已就绪后的执行过程：延迟字段校验、业务响应、轮询等待、下载、SDK 单元格准备和已发出写入的返回，卸载真实 Vue 实例后再放行。核对不再补列、切表、请求或写下一行；内部捕获不能把卸载当作可跳过失败继续执行，顶层静默收尾。已发出且可能生效的请求／写入不作撤销保证，断言其返回后没有新增操作；不能仅以不更新界面证明没有副作用。
- 涉及字段创建、校验、映射、值转换和恢复写入时，同时遵守[字段类型与写入规则](field-write-rules.md)；逐一核对默认类型、已有列兼容范围及实际写入，不以配置声明或校验通过代替落表验证。
- 输出方式和目标表共同决定当前配置；“已有表 → 新建 → 切回原已有表”须恢复该表映射和写入方式，加载等待或读取失败时不得按空映射启动。失败后执行先重读目标字段并恢复映射，保留原始错误；再次失败显示本次原因，不发业务请求或写入。回归检查原目标列的实际值及未选字段，防止提示成功但另建默认列。任务恢复仍使用原任务配置。保存未完成时切走再切回，保留该表最新待保存配置，不按旧缓存回退或误回存（包括热榜及提取视频文案、小红书下载、链接转附件在已有表与当前表之间切换）；读取收尾不能清除真实保存结果，待保存不等于已保存。期间有更新的成功保存，或读取捕获的保存自身成功时，旧成功／失败响应都不能回退该表配置、清空映射或阻塞已确认的配置；读取前已完成的历史保存不能掩盖新读取错误，不同表的保存结果分别判断。三个工具页配置未就绪时实际点击“立即执行”，须先显示读取阶段的进度并保持原忙碌互斥，读取失败显示本次原错且不补列、不请求业务；停止等待和卸载后不继续执行，新建表不依赖旧表配置。三个工具页当前表映射的保存目标随已加载字段固定，首次等待前即登记快照；保存时活动表读取延迟或活动表变化，不得将本次编辑归到另一张表或让切回操作丢失草稿。
- 使用已有表时，写入方式和字段映射的源列／目标列、添加／删除按钮在目标配置未就绪、读取等待或失败后待重读时保持禁用；读取成功并应用当前目标表配置后才允许编辑，字段与云配置的返回顺序不能跳过该步骤，也不能把用户选择静默覆盖。提取视频文案、小红书下载、链接转附件的云端输出配置等待或读取失败时同样保持映射编辑和自动保存锁定，显示实际读取阶段、原始错误及云配置同页“重试”；成功应用目标表映射后才解锁，成功空列表仍沿用默认行为。聚合评论及提取视频文案、小红书下载、链接转附件的目标字段读取失败时显示原原因和同页“重试”；映射编辑与自动保存同时拦截临时空配置。字段重试保留原草稿，读取成功后再解锁，不能以重试为由回存旧映射。配置就绪不得解除执行／恢复阶段的原忙碌保护；检查“始终新增”的实际追加行数及原行保留。
- 使用已有表时，云端配置未成功读取与“成功但没有配置”必须区分。失败后点击执行先用原忙碌状态显示配置读取进度，重读成功并应用映射后再校验／补列及执行；再次失败显示原原因且不写表、不自动保存空映射。作者作品不能先补列再拦截提交。已有任务恢复和待写结果续写沿用原快照；新建目标不受旧表配置错误阻塞。

- 审核开始先列出受影响能力在聚合插件、独立作者搜索、独立推荐词及独立评论中的实际入口，区分共用实现与独立实现；每个入口标明适用、已验证或未验证。先检查完整使用流程，再确认本次修复，验证深度按影响选择，无需每轮重测无影响路径。
- 以用户操作串联状态，核对提示文案、允许的下一步、按钮及动画、任务身份、已写入结果是否一致。不能只看字符串、结构化标记或函数名称；例如“恢复”应继续原任务，“正在清理”不能仍允许停止，“处理完成”不能掩盖未完成或失败的结果。
- 搜索任务恢复时，表单应回显原任务保存的关键词、平台、范围及输出配置，字段映射和写入方式沿用任务快照，不被较新的云端草稿覆盖，也不将恢复回填自动保存为云端草稿。字段回显加载不阻塞原任务轮询或停止确认，迟到成功／失败仍按原加载归属处理；任务先结束后字段再返回，也不得误保存任务映射。关键词搜索切换新建表格时使旧字段读取失效，保留已有表草稿；切回同表时，已加载的原草稿继续保留，未读完或读取失败则重读。恢复前尚未建表的批量搜索沿用首关键词命名。创建任务前固定独立快照，创建响应延迟时不能混入后续表单变化；缺少表单快照的旧任务仍沿用已有任务身份和写入进度，不重新创建任务。

| 阶段 | 按入口实际能力选择的场景 | 核对重点 |
| --- | --- | --- |
| 校验与准备 | 同步校验、字段类型或映射错误、配置读取失败、创建响应延迟、密钥保存等待 | 具体原因、进度出现时机、同页修正入口、忙碌互斥及防重复提交 |
| 获取 | 正常、空结果、单条失败、鉴权失败、网络错误及超时 | 是否应继续；同时检查业务错误码与HTTP错误，区分业务API和资源下载错误 |
| 写入 | 分批、部分成功、失败重试、已生效但响应失败 | 实际数量、游标及检查点、原目标表和结果保留、是否可能重复新增 |
| 停止与清理 | 停止等待、停止后剩余写入、清理等待或失败、旧请求晚返回 | 真实阶段、按钮禁用及加载、旧请求归属、是否提前允许新建 |
| 恢复 | 同页恢复、密钥更新、进度缺失、表格不匹配、卸载后重进 | 原任务身份及配置、可执行的恢复动作、必要保护是否仍有效 |
| 终态 | 成功、空结果、部分失败、全部失败、最终停止 | 图标、文案、数量、停留时间及执行中提醒是否符合实际结果 |

- 对“关闭、刷新、重新进入插件”等要求追到错误来源，确认是否确有在途写入、身份或进度无法确认等限制；普通校验、配置及只读错误优先核查现有同页重试能力。既不能照搬旧提示，也不能仅为解除禁用而移除必要的写入保护。
- 回归围绕用户可见行为和实际状态边界，覆盖相关正常与失败路径、延迟或迟到响应、同能力其他入口。新增缺陷用例应能在修复前复现；不以源码包含某字符串或只断言标记值代替行为验证，不为静态文档新增逐字测试。
- 映射锁定须用真实下拉及按钮验证控件自身的禁用和点击行为，不能由父表单禁用推断；Element Plus 的显式 `disabled=false` 会覆盖表单禁用。覆盖执行、停止等待、写入及已有能力支持的待续写阶段，继续写入仍用原任务映射，完成或明确结束后恢复编辑。
- 涉及界面表现时，在真实页面核对布局、换行与间距、按钮文案、悬停/按下/键盘聚焦、禁用及加载动画。共享样式选择代表入口检查，各入口的交互差异分别验证；飞书宿主相关行为在真实侧栏检查。本地故障注入可以验证异步边界，但须标明环境，不能称为已在飞书验证。
- 收尾简要记录验证的入口、场景、环境、结果和未验证项。源码检查、真实Vue/Element Plus测试、本地浏览器及真实飞书验证分别说明；测试数量不代表场景完整。“未发现问题”仅限本轮检查范围，未完成真实界面验证时不得宣称整体界面验收通过。构建、发布及生产操作仍按用户授权执行。

### 具体回归场景

- 延迟目标表读取、字段校验或任务创建响应，点击执行后等待期间应已显示居中加载，按钮和配置处于原有忙碌锁定状态；每个入口及已接入的新建表、现有表、手动输入和表格输入路径按实际能力验收。切表后旧读取的成功、失败及收尾只作用于原归属，不能覆盖新表配置、误保存或提前解除新表加载；切换新建和卸载同样使旧读取失效。映射下拉的字段列表同样检查，包含评论及提取视频文案、小红书下载、链接转附件的已有表／当前表路径；通过实际选择目标列和保存载荷确认不会把旧表列 ID 保存到新表。独立作者提交前固定输出配置，异步校验和创建后的保存、写入使用同一快照。
- 同步校验失败只显示具体错误，不发业务请求；异步准备失败或返回空结果后不残留加载状态。
- 检查每条执行中提示仅含一次勿关闭提醒，停止后的写入阶段使用专用提醒，终态及非任务配置消息没有执行中提醒。
- 真实 Vue 生命周期验证新任务不被旧提示计时器隐藏；提示更新不清任务进度、不绕过互斥状态、不重复提交。
- 独立作者页面卸载后，迟到的初始化不得恢复旧实例；已经发出的创建成功后先保存任务身份，由重进页面恢复。同一运行时重挂载时，先等待旧提交、身份保存、在途表格批次写入及其游标保存、进度清理结束，再恢复或允许启动，旧收尾回调不得重新弹出提示。已成功批次的游标保存失败时，仅补存已有进度，不重发该批写入；批次写入失败则保留原游标及已经创建的目标表。
- 后续定时轮询的进度保存和补存均失败时，显示原错误并保留重进保护，停止本地轮询；不能留下可点击的停止入口或永久“正在停止…”状态。普通鉴权暂停仍允许更新密钥恢复原任务。
- SDK 写入报错不能直接视为未落表。独立作者更新模式重新读取实际作者索引；追加及缺失身份信息的记录，复用当前失败批次检查点核对新增行，只补缺失部分，不抵扣历史重复记录。写入前检查点保存失败不得发送 SDK 写入；核对字段、结果数量或新增记录有歧义时，沿用原错误暂停及重进保护。 URL字段的属性顺序差异不应被当成内容差异；链接和显示文本仍分别参与匹配，不合并真正不同的值。
- 独立作者鉴权暂停后保留已知任务身份，主按钮显示“恢复任务”，点击后使用原任务设置及游标；恢复执行后显示“停止任务”，任务结束且无恢复保护时回到“立即执行”。API Key保存成功时，同值和换值均进入已有恢复逻辑；只显式保存成功才自动恢复，保存失败不自动重试。恢复读取/状态请求等待期间继续互斥，不得创建新任务覆盖旧taskId及游标；重开保护不能被保存事件清除。同值保存保留当前字段映射草稿，换值继续原字段加载行为。按钮文案根据任务身份及恢复标记切换；只读失败尚未读到taskId时，也保留“恢复任务”，不放开新建。

- 推进异常浮层的 5 秒计时后，原错误和核对建议仍在任务操作区；要求重开的异常不能在本页直接恢复，保留相应按钮状态和处理说明。
- 验证停止且成功/失败计数分别为 2/1、0/1、2/0：前两种警告 5 秒，后一种中性 3 秒；均保留统计且不附带执行中提醒。
- 首条记录普通失败、后续请求延迟时，整批加载、勿关闭提醒及忙碌锁定持续，最后按实际数量汇总；鉴权等致命错误仍中止整批。

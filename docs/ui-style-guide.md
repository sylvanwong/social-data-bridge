# 界面样式规范

公共定义位于 `src/assets/typography.css`，由 `src/assets/main.css` 加载。首页与作品详情、作者信息、作者作品页面已接入；其他页面后续修改时沿用，暂不整体重写。

| 用途 | 字号 | 字重 |
| --- | --- | --- |
| 首页主标题 | 20px | 600 |
| 子页面标题 | 18px，个别紧凑页沿用 15px | 按已有层级 |
| 首页「API Key 设置」标题 | 16px | 600 |
| 首页功能卡片名称，如「作品详情获取」 | 14px | 500 |
| 功能页分区标题 | 16px | 500 |
| 表单标签、展开标题 | 14px | 500 |
| 正文、选项 | 14px | 400 |
| 次要链接 | 13px | 400 |
| 可选标记、提示文字 | 12px | 400 |

- 字体使用 `--app-font-family`，字号和字重使用对应的公共变量。
- 字段映射、筛选条件的展开标题使用 `.ui-disclosure-label`（行高 22px），辅助文字使用 `.ui-disclosure-meta`。
- 不以 `font: inherit` 作为展开标题字号的唯一来源，父容器可能不同。
- 相同语义使用相同样式；首页主标题、API Key 设置标题、功能卡片名称和功能页标签保留各自层级。

## 主执行按钮

- 四插件任务按钮统一为 36px 高、6px 圆角、14px/500 文字。执行沿用红底白字，悬停及按下背景分别为 `#c11126`、`#8a0515`，交互文字保持白色；Element Plus 自定义 `color` 不覆盖这份任务按钮规范。
- 停止按钮保持浅底红字，悬停 `#fff1f2`、按下 `#ffe4e6`；禁用及加载统一为 `#fafafa` 灰底和 `#86909c` 灰字，加载蒙层不再次淡化配色。
- 键盘聚焦只将原边框加粗至 2px 并加深，不叠加外圈或阴影，不反色、不改变外部尺寸；聚焦不触发任务操作。颜色过渡 100ms，按钮加载图标 2s 匀速旋转，居中提示 0.8s；减少动态效果时取消过渡和旋转。
- 状态文案及可用性以[最终规范的任务按钮定义](task-feedback-final.md#任务按钮样式文案与动画)为准，复用既有任务、停止、恢复、续写及API Key互斥状态。
- 任务操作（执行、停止、恢复、继续写入、结束本次写入）使用有边框的主、次按钮。配置区域的重试、重试保存、重新读取，以及字段映射增删、筛选条件编辑，保留与对应内容相邻的红色文字按钮，不套用任务按钮的满宽布局。
- 独立推荐词待续写时，“继续写入”保留红色主按钮；“结束本次写入”使用白底灰边次按钮。两个按钮均占满可用宽度、高度 36px，左右对齐、上下间隔 8px，不继承 Element Plus 相邻按钮的左外边距；禁用时均使用统一灰底灰字。键盘聚焦只强化原边框。错误和剩余进度说明位于按钮上方；结束、续写及禁用条件沿用现有逻辑。
- 独立推荐词继续写入的准备及实际写入阶段，复用现有 `submitting`、`loading` 状态隐藏“结束本次写入”，保留主按钮原有的禁用加载状态，实际写入时显示“执行中…”。再次失败且仍有待写结果时恢复两个按钮及 8px 间距；全部写完后恢复“立即执行”。隐藏按钮不结束任务、不清除待写结果，API Key 保存期间仍沿用原禁用保护。
- 聚合/独立推荐词的获取阶段及独立评论的后台获取阶段也使用“停止任务”；停止等待使用禁用加载的“正在停止…”，单纯写入阶段不提供停止。适用边界及停止文案见[停止能力与边界](task-feedback-final.md#停止能力与边界)。热榜仍为单次请求的“执行中…”。
- 浏览器回归入口：四个插件各自开发服务的 `/tests/buttonStates.html`。页面加载实际组件 CSS 和 Element Plus，逐个点击及用 Tab 聚焦按钮，核对每项 PASS/FAIL 和禁用状态；该页面不执行业务组件的任务逻辑、不调用生产接口。

## 间距

公共间距变量位于 `src/assets/main.css`。表单采用以下三档，不为单个页面另建一套数值：

| 用途 | 间距 | 变量 |
| --- | --- | --- |
| 标签到控件、组内相关内容 | 8px | `--app-space-control` |
| 相邻配置组，例如输出字段、字段映射、执行方式；表单到操作区 | 16px | `--app-space-group` |
| 输入设置与输出设置等主要分区 | 24px | `--app-space-section` |

- 间距按容器边界计算，由父容器的 `gap` 或单侧外边距负责，不叠加子项外边距、Element Plus 默认表单外边距或内联样式。
- 展开标题保留至少 32px 的点击高度；展开内容距标题容器 8px，收起时不保留内容占位。按钮内部留白属于点击区域，不再额外添加上下 padding。
- 同层级配置组使用留白分组，不额外叠加分隔线。
- 作品详情、作者信息、作者作品的主表单输出设置共用 `src/assets/output-layout.css`，覆盖展开、收起以及不显示字段映射的情况。主表单的配置组布局不直接套用到任务弹窗和首页卡片；这些区域后续调整时按相同语义选用间距变量。

## 提示反馈

本节是聚合插件及对应独立侧栏插件的统一规范，尚不表示各页面已经完成代码迁移。任务文案以本节列出的源码为准；样式示意图中的缩写、演示数量和新增提示不能直接作为生产文案。

聚合插件的[文案与样式最终稿](task-feedback-final.md)列出逐功能的完整文案、状态及明确修正；以下“现有文案基准”用于核对迁移前的源码现状。

### 点击执行立即反馈

- 点击“立即执行”后，密钥、关键词、必填项等同步校验失败时直接显示具体错误；校验通过后立即进入现有忙碌状态并显示居中加载提示。
- 首条进度必须先于首次异步操作，包括配置或表格读取、异步字段校验、创建和提交任务；不能等读取记录完成、接口返回或取得任务 ID 后才显示。按钮加载不能代替居中提示。
- 已有明确的首阶段文案时直接使用，例如推荐词的当前关键词；缺少时使用最终稿规定的启动提示。随后按真实阶段更新同一条提示，不人为增加延迟、不伪造进度，必要时沿用 `await nextTick()` 使 Vue 更新能够渲染。
- 继续执行、恢复任务同样先反馈再异步处理。同步拒绝、重复点击、准备失败及无数据提前退出要正确保留或结束当前状态，不能留下永久转圈。

### 执行中勿关闭提醒

- 启动、任务准备、读取任务数据、获取、核对、写入、恢复等仍需插件页面运行的阶段，统一带一次 `请勿关闭插件，关闭将中断任务`。原文已经带有提醒时不重复追加；现有页面缺少提醒的，迁移时必须补齐。
- 停止请求已发出、仍需等待当前操作或写入剩余结果时，使用 `请勿关闭插件，关闭会中断数据写入`；共享停止函数的原文和阶段含义保持不变。
- 成功、最终停止、纯空结果、已结束的部分失败或整体失败，不带执行中提醒。单条失败但整批继续时仍带执行提醒。参数校验、保存设置和非任务的配置加载也不带；作为执行前置步骤的异步字段校验属于任务准备，应带提醒。
- 独立推荐词的本页待继续写入状态，保留关闭或刷新会清除未完成进度的专用说明，不与聚合持久化任务的执行提醒互换。

以下源码文案表保留现状用于追溯；原文中缺少上述首次反馈或执行提醒，不能作为迁移后继续缺失的理由。

### 外观与位置

- 任务提示复用 [CommentFetch.vue](../src/components/CommentFetch.vue#L1579) 的 `.toast-wrap`、`.toast`、`.toast-icon` 结构和 [对应 CSS](../src/components/CommentFetch.vue#L1731)。字体、加载 SVG、实心绿色成功勾直接沿用原实现，不重新绘制。
- 相对插件可视区域居中，保持 `top: 50%; left: 50%` 和居中位移，不放在表单底部，不随表单滚动。
- 保持白底、`1px #e5e6eb` 边框、8px 圆角、原阴影、`10px 18px` 内边距；图标 18px，图文间距 8px，文字 14px、字重 500，字体沿用所在页面，行高统一为 22px，避免继承页面重置样式后多行文字拥挤。
- 内容仍是“图标 + 一段文字”。不新增标题、分层说明、关闭按钮、遮罩或固定宽度卡片。宽度随内容变化，最大为可视区域减去两侧各 24px；长文本自然换行，连续链接也不能撑出提示框。
- 任务提示保持 `pointer-events: none`，不拦截底部操作，不抢焦点。按钮可用性由现有任务状态决定。
- 加载、成功保留原图标。警告、错误、中性状态补齐与现有提示一致的实心圆形 SVG 图标，颜色分别为 `#ff7d00`、`#f53f3f`、`#86909c`；失败、停止和无结果不能继续使用绿色成功勾。
- 顶部 Message 同样使用 22px 行高，两侧各至少留 24px；局部配置及暂停说明保留所在操作区的正文间距，不套用浮层布局。
- API Key、用户主动保存设置和提交校验使用现有顶部 Message；表格配置加载、失败及重试保留在对应配置区域。原右上角 Notification 逐项迁移，不能与居中任务提示重复展示同一错误。
- 迁移时保留业务条件与错误返回。不能删除底层通知后漏掉调用方没有处理的错误，也不能为统一位置而新增任务、重试或全局通知系统。

### 状态与显示时间

| 场景 | 展示与时机 | 说明 |
| --- | --- | --- |
| 准备、获取、写入、恢复、核对中 | 居中加载，持续到阶段变化或结束 | 更新同一条提示，不堆叠多条 |
| 正在停止获取、停止获取后仍在写入 | 居中加载，直到结果写入结束 | 必须区分两个阶段，见下文停止文案 |
| 停止请求失败，任务仍在执行 | 顶部 Message 报告一次原错；居中持续显示进度及勿关闭提醒 | 未确认停止时恢复执行提示；轮询已确认取消或停止时保留停止阶段、写入专用提醒及操作锁定 |
| 全部成功、写入完成且无失败的已停止 | 居中结果，3 秒自动消失 | 成功使用成功图标，纯停止使用中性图标 |
| 写入完成后的已停止且有失败 | 居中警告，5 秒自动消失 | 优先保留停止语义和成功/失败统计；即使成功数为 0，也不把用户停止标为整批执行失败 |
| 已结束的部分成功、无结果或普通失败 | 居中对应状态，5 秒自动消失 | 部分失败用警告；全部失败用错误；纯空结果用中性图标 |
| 字段类型不匹配错误 | 沿用对应浮动提示，8 秒自动消失 | 仅延长时间，原文案、操作状态和说明保留规则不变 |
| 写入结果待核对、必须重开的暂停异常 | 浮层可在 5 秒后消失；操作要求保留在任务区 | 原错误和前置处理建议不能随浮层丢失，恢复入口与原状态一致 |
| 单条非致命失败，整批仍继续 | 保留居中加载和勿关闭提醒；原错误就地说明 | 不切换整批终态、不解锁操作，结束后按原计数汇总 |
| 本页有结果可继续写入 | 根据原因显示居中提示，5 秒自动消失；实际写入或字段异常用错误图标 | 原错误及续写要求留在操作区；待写入缓存、API Key 锁定、继续和结束操作继续保留 |
| 主动保存设置 | 顶部 Message，成功 3 秒、失败 5 秒 | 文案保留设置对象；有原关闭能力的 Message 可手动关闭 |
| 阻止提交的校验 | 顶部短消息，3 秒自动消失；字段类型不匹配为 8 秒 | 优先沿用具体字段提示；已有就地错误说明保留，不改成泛泛的“请补全必填项” |
| 配置加载、连接与就地重试 | 原区域持续显示，成功或修正后消失 | 重试入口及是否需要重新打开插件以原页面为准 |

已统一采用上表时长；任务提示由 `useTaskFeedback` 管理更新、计时及卸载清理，配置提示使用顶部 Message。

计时器在新提示、重新执行、卸载时清理；旧结果的计时器不能隐藏新任务进度。提示自动消失只影响展示，不清缓存、不停止任务、不解锁 API Key。同一错误只弹一次浮动提示；必要的任务区说明可以保留，不是第二个弹窗。

### 复合状态与人工处理要求

- 需要核对表格结果或重新打开插件的异常属于暂停状态，不能统一成“失败提示 5 秒后只剩恢复按钮”。原错误和必要要求复用任务操作区的普通 `.sub-hint` 说明展示，浮层消失后仍可查看，直到恢复、结束或离开当前任务处理。
- 普通可恢复异常保留“恢复任务”按钮，说明先核对再恢复；已有 `requiresReopen` 等条件要求重开时，本页入口禁用。有持久化任务恢复能力的页面显示“请重新进入插件恢复”，其余显示“请重新进入插件”。独立推荐词还需说明未写结果会清除、重开后需重新执行。不增加确认框、核对勾选、消息历史、新重试逻辑或新状态机。
- 这些暂停说明不附带执行中“请勿关闭”，避免与原始错误里的“请关闭当前插件后重新打开”相矛盾。按钮和恢复行为继续服从已有状态，不能只根据文案判断。
- 最终停止且 `failCount > 0` 使用警告、5 秒；最终停止且无失败使用中性、3 秒。仍在停止和写入收尾时不进入这个结果分类。
- 对原逻辑允许继续的记录级错误，不隐藏居中加载、不释放忙碌状态、不去掉勿关闭提醒；最近的原错误可在任务操作区就地说明，补明“整批任务继续执行”，原位更新，不逐条堆叠终态提示。结束后复用原成功/失败计数汇总。
- 鉴权等原本中止整批的错误仍按整体异常处理，不能为了保持执行中状态而吞错；不新增失败日志面板、单条重跑或重试队列。具体示例见[最终稿审阅补齐章节](task-feedback-final.md#审阅补齐暂停停止伴随失败单条失败继续)。

### 文案保留规则

- 保留原页面的对象名称、阶段、计数单位、错误原因和必要提醒。“作者”“作品”“评论”“短剧”“主页”“搜索页”不能统一删成“数据”或“条”。
- 获取进度与写入进度分别表达。处理了 2 个关键词、搜索页或主页，不等于写入了 2 条结果；批次大小也不是总结果数。
- 推荐词显示当前关键词和进度；完成摘要保留“几个关键词无结果”“几个关键词获取失败”，不把失败关键词数换成失败记录数。
- 错误文案沿用页面现有取值顺序及兜底信息。没有权限错误证据时，不擅自补“检查访问权限”；接口可能暂时失败时，不把“检查 API Key 或稍后重试”缩成只有“检查 API Key”。
- 保留执行中的 `请勿关闭插件，关闭将中断任务`，以及停止写入中的 `请勿关闭插件，关闭会中断数据写入`。不能一概删除，也不能给所有功能追加“刷新会清除进度”。
- 本页缓存恢复与服务端持久化任务分别说明。独立推荐词的“继续写入”不等于聚合任务的“恢复任务”，二者不能互换；聚合推荐词当前没有独立版的本页续写能力。
- 继续使用原页面的完整句子和省略号。示例中的斜杠、分行标题、缩写、`已确认` 等演示用表达不是替换原文的要求。

### 停止与恢复必须区分的阶段

[taskStopText.js](../src/utils/taskStopText.js) 已为作者搜索、关键词搜索、作者作品、评论和短剧复用停止文案，继续沿用：

### 独立插件和新增场景的边界

以下不是聚合插件现有文案，不能在规范或预览中标成“聚合原文”：

- 独立推荐词 [ApiKeySettings.vue](../../social-suggestion-search/src/components/ApiKeySettings.vue) 的 `API Key 已保存`、`API Key 已清空`、`保存 API Key 失败，请重试`、`正在连接多维表格…`、`重新连接`。连接失败原文为 `请在飞书多维表格扩展中打开此页面，以读取 API Key 并将结果写入表格。`，不能缩成不说明使用环境的“连接失败”。
- 独立推荐词 [SearchSuggestions.vue](../../social-suggestion-search/src/components/SearchSuggestions.vue#L287) 当前写入进度为 `正在写入多维表格，已写入 {written}/{total} 条…`；失败后保留的正文为 `已写入 {written}/{total} 条，可继续写入本次剩余结果。请保留当前页面，关闭或刷新会清除这份进度。`。移动到居中时保留信息，不擅自添加“请求超时”；失败也可能是字段、初始化、读取或写入错误。
- `继续写入`、`结束本次写入` 仅保留在已有本页缓存的独立推荐词流程。其现有结束操作不弹结果提示；不为了补齐示意图新增“本次写入已结束”提示。
- 批次响应超时仍需核对实际落表情况。规范中的写入数量必须来自已成功确认的批次，不能断言未确认部分尚未写入，也不要求把原文 `已写入` 全部替换为 `已确认写入`。
- `数据已写入，打开结果表失败` 是可用于未来区分收尾错误的候选文案，不是聚合现有提示。只有已确认全部落表、失败点确实是打开结果表时才能使用，并保留实际原因。

### 已发现、待代码迁移修正的问题

1. 多个页面只区分加载和非加载，失败、停止也显示绿色成功勾；部分路径同时弹居中提示及 Notification。统一图标及错误出口时，保留上述原文和错误原因。
2. 作品详情的正常完成文案仍拼接 `请勿关闭插件，关闭将中断任务`，与已结束状态不符。后续仅在任务仍运行或仍在写入时保留提醒，最终结果去掉该后缀；这不是要求删除其他页面执行中的提醒。
3. 推荐词已有失败关键词摘要，但完成提示仍显示绿色成功勾。结果含获取失败时保留原摘要，改用警告图标；成功落表的条数仍按实际数据展示。
4. 推荐词部分请求失败、其余无结果时，当前仍落入“未获取到推荐词”的分支。应补充失败与无结果的区别，作为有业务条件的新文案单独实现和测试，不把候选句写成源码现状。
5. 独立推荐词待继续写入时，API Key 提醒仍是 `任务处理中，完成或停止后可修改 API Key。`，而本页操作叫 `结束本次写入`。后续仅对这一路径改为与实际操作一致的提醒，其他具有“停止任务”的页面继续保留自己的说法。

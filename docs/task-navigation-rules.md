# 执行期间的返回规则

插件内返回按任务是否能恢复判断，不按功能名称或是否有后端任务 ID 判断。只限制当前页面，不限制其他浏览器页面创建独立任务。

| 功能 | 当前执行方式 | 插件内返回 |
| --- | --- | --- |
| 作品详情获取、获取作者信息 | 页面逐行请求并写入，无恢复入口 | 执行及停止等待期间禁用 |
| 小红书下载、链接转附件 | 页面转换、下载或写入，无恢复入口 | 执行及停止等待期间禁用 |
| 视频文案提取 | 后端处理，页面轮询并写入，无恢复入口 | 执行及停止等待期间禁用 |
| 博主短剧获取 | 后端采集，页面轮询并写入，无恢复入口 | 提交、执行及停止等待期间禁用 |
| 热榜获取 | 页面请求并写入，无恢复入口 | 提交检查及执行期间禁用，等待结束 |
| 获取作者作品 | 保存任务进度，重新进入可恢复轮询和写入 | 保留允许返回 |
| 关键词搜索获取、评论获取 | 使用 useIncrementalTask 保存进度并恢复 | 保留允许返回 |

禁用返回时显示提示“请等待任务结束后返回”；有停止按钮的页面可先停止，等待停止完成后返回。失败、正常完成后沿用现有运行状态恢复返回。定时任务列表的读取不构成执行锁定。

本规则只控制插件内返回按钮，不承诺阻止关闭浏览器、刷新或关闭插件。

## 恢复能力的已知边界

三个有恢复入口的功能均使用各自固定的 bridge 存储键，尚不具备多任务恢复记录隔离及跨页面唯一写入者控制。允许返回不等于已经验证多页面恢复安全；本次不重构这些机制。

飞书官方说明 setData 在同一文档的同一插件内共享：https://lark-base-team.github.io/js-sdk-docs/zh/api/bridge#setdata 。后续处理恢复能力时应同时考虑这三个功能。
